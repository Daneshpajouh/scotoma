The complete offline replay is `./reproduce.sh`. Run it from any directory. It uses the required isolated Python interpreter, a lowered scheduling priority and four computational threads. All writes stay in this task directory. The frozen typography source makes the layout check independent of later manuscript edits. NumPy, h5py, SciPy, pdfTeX and Poppler must already be installed.

`produce.py` verifies the pinned inputs, joins the assay sequences, constructs the score-independent control, exhaustively checks the encoder convention against the original implementation, and only then scores. Its convolution/recurrent implementation is an unchanged copy of the previously validated `model_numpy.py`. `vendor/verify.py` is the unchanged, separately implemented reference forward pass from that same validation deposit.

`verify.py` independently parses the raw released outputs and uses a disk-backed SQL table to reconstruct the control sample. It checks every selected alignment against the original run, every converted tensor against the original encoder, every score against the reference forward pass, exact rational cutoff decisions, every numerical summary, paired per-guide output, the findings text, rendered line counts, and actual rejection of the corrupted input. It prints its exit code. The `--scores-only` option bootstraps verification before report creation; the default also requires the finished report and its integrity controls.

The raw control archive was retrieved as a read-only tar stream from the original completed whole-assembly run. `retrieval.json` records the exact command and members; the archive contains the original byte digests in chromosome analysis summaries, which are themselves checked against the corresponding run records. The collected guide and chromosome exports must also be byte-identical to the local deposit. No cluster job, rescan or remote output file was created.

Control selection matches guide, four protospacer substitutions, one RNA bulge and strict NGG. The selection rank is SHA-256 of the literal tab-separated string `aligned-control-v1`, guide, chromosome, strand and decimal PAM boundary. Each guide gets the same number of distinct control loci as treatment loci. Where several eligible released alignments describe one selected locus, the smallest DNA string is used. Scores do not enter selection. Unselected loci and unsupported ambiguous alignments are not scored. Chromosome and gap location are not additional matching variables.

Assay `row_index` refers to the selected `sites129.json` record, not to a source CSV line. Each join checks guide, coordinates, strand, real PAM and positive measured reads. Source mismatch labels include PAM substitutions on non-NGG rows; the producer and verifier split those from protospacer mismatches before grouping. Both active arms use the deposited terminal alignment and guide spacer plus `NNN`. In-scope omitted assay rows must also match a scored corrected-only genomic locus.

The primary human-readable deliverable is `../FINDINGS.md`. `results/summary.json` contains the distributions and all paired guide summaries; `results/per_guide_scores.tsv` is the compact guide table. Each arm has a complete score table. `results/encoder_convention.json` and `results/execution.json` preserve the pre-scoring gate and its ordering. `INPUT_SHA256.tsv`, `pins.json` and the hard-coded digest in `integrity.py` seal the inputs and reused implementations. `SHA256SUMS` seals the final artifacts; `seal.py --verify` checks it.

`corruption_control.py` changes exactly one DNA byte in a copy of the corrected-only input. The unmodified input must pass and the changed copy must fail at the input seal before scoring. The copied tree uses read-only symlink targets for unchanged files; no source file is mutated. The final verifier repeats this rejection and audits the byte difference.

`layout/sentence_layout.pdf` typesets the proposed body sentence and exact removed sentence using the current body font and geometry. The verifier counts rendered PDF lines independently of the typesetter's line counter. The image was inspected. This is an isolated line-budget check; no paper source was edited and no complete revised-paper pagination is claimed.

The retained `logs/producer_preflight_failed.log` is an implementation preflight failure before any scoring: it exposed the assay's inclusion of PAM substitutions in its mismatch label. The repaired grouping recomputes protospacer mismatches and verifies the complete label decomposition. The successful scoring and final replay logs are separate.

These are retrospective in-silico nominations. They do not establish cleavage, clinical risk, independent test-set performance, top-rank changes, or calibration of the published cutoff for this combined-data checkpoint. PAM strings remain literal, but guide `NNN` copies those symbols in the encoder and therefore does not measure PAM specificity. Reference sequence correctness was asserted by the original run; this replay authenticates the exported inputs and provenance without re-reading the assembly.
